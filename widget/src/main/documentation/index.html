DocRAG Widget

This resource-only JAR contains an ES module at /document-research/chat-widget.js. No Java classes are provided. The sources artifact contains the original JavaScript assets.

import {mount} from '/document-research/chat-widget.js';
const chat = mount({apiBase: '/api/research', title: 'Report research'});
chat.open();
chat.close();
chat.setContext({documentIds: ['uploaded-id']});
chat.destroy();

mount(options) appends a document-research-chat Web Component to the document body. open() and close() control the panel; destroy() disconnects listeners and progress subscriptions. setContext(context) supplies optional page context, not trusted caller identity.

Serve the authenticated same-origin API through the Spring adapter or implement its HTTP contract. The host owns authentication, authorization and CSRF configuration. Never include model/database credentials in browser options. Progress uses Server-Sent Events. Answers render as text with expandable citations. Uploaded reports are shared; conversation history is owner-scoped. Browser storage retains only the conversation identifier.

See the versioned HTTP and mounting documentation and installation examples.
